# Still excluded (see requirements-ci.txt's own header for why): prophet,
# chromadb, sentence-transformers, snowflake, bigquery. Their call sites are

# demo doesn't need them, and installing them would blow the cold-start/
# memory budget on Streamlit Community Cloud's free tier.
#
# openai/anthropic are ALSO excluded: ANALYST_MODE=offline (the default —
# see core/config.py) never imports them, since it blanks the API keys that
# every LLM call site checks before even trying. Full mode requires them —
# install requirements.txt instead for that.
